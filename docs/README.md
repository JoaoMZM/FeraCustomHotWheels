# Fera Custom HotWheels - Sistema de E-Commerce e gerenciamento de estoque

  Este repositório contém o projeto em desenvolvimento e documentação do sistema produzido para o cliente FeraCustom, que requere um sistema de E-Commerce especializado na       venda de artefatos HotWheels. A aplicação é feita com propósito acadêmico, mais especificamente, o TCC (Trabalho de Conclusão de Curso).
  
## Ojetivo
  Objetivo de propósito de acadêmico, com objetivo de realização do TCC para o Curso Técnico em Desenvolvimento de Sistemas da Escola SENAI "Dr. Celso Charuri". O projeto        busca também, sanar dificuldades de gerenciamento de negócios do cliente, aplicando conhecimentos adquiridos no curso técnico: 
  - Modelagem e relacionamento do banco de dados;
  - Programação Back-End;
  - Programação Front-End;
  - Desenvolvimento Mobile;
  - Desenvolvimento de design e interfaces;
  - Metodologias de desenvolvimento;
  - Arquitetura de sistemas;
  - Documentação e levantamento de requisitos;
  - Versionamento.

## Tecnologias Utilizadas

  ### Front-End
    - HTML5;
    - CSS;
    - JavaScript;
    - React;
    - Bootstrap.
    
  ### Back-End
    - Node.js;

  ### Banco de dados
    - SqlServer;

  ### Documentação
    - Word;
    - GitHub (Este README.md);
    - Draw.io (DER).

## Funcionalidades
  - Cadastro de usuários;
  - Cadastro de produtos;
  - Sistema de login;
  - Sistema de pagamento;
  - Rastreamento de entrega;
  - Contato com cliente vendedor;
  - Gerenciamento de estoque dos produtos;
  - Carrinho de compras.

## 📖 Sobre o Projeto

Este repositório contém o projeto em desenvolvimento e a documentação do sistema produzido para o cliente **FeraCustom**, que requer um sistema de E-Commerce especializado. A aplicação é desenvolvida com propósito acadêmico, representando o TCC (Trabalho de Conclusão de Curso) para o Curso Técnico em Desenvolvimento de Sistemas da Escola SENAI "Dr. Celso Charuri".

O projeto busca sanar as dificuldades de gerenciamento de negócios do cliente, aplicando na prática os conhecimentos adquiridos durante o curso.

### 🎯 Objetivos de Aprendizagem
Durante o desenvolvimento, a equipe aplica e consolida conceitos de:
- Modelagem e relacionamento de banco de dados
- Programação Back-End e Front-End
- Desenvolvimento Mobile
- Design de interfaces (UI/UX)
- Metodologias de desenvolvimento e Arquitetura de sistemas
- Documentação, levantamento de requisitos e Versionamento
